# Commit messages

- Write all future commit messages for this project in English.
- Describe each change on a separate line.
- Start every change line with `- ` and end it with `;`.
- The complete commit message must start with `-` and end with `;`.
- Do not add a separate title or text outside these change lines.

Example:

```text
- Add automatic patient literature discovery;
- Update documentation and relevant tests;
```
